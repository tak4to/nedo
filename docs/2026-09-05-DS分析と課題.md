## 2. 統計的な検出力の分析 — **これが最大の方法論的問題**

対応のある差（同一シーンでの前後比較）の標準偏差を実測した。

| 比較 | 対応差の sd |
| --- | --- |
| ほぼ同一コード（ノイズのみ） | **0.75** |
| 棚下候補 vs 現行 | 4.52 |
| CEM最良 vs 現行 | 5.04 〜 5.37 |
| `SUPPORT_LIFT` 前後 | 6.08 |

**実際の施策では sd ≈ 5**。これは測定ノイズ（0.75）ではなく**処置の異質性**
（シーンごとに反応が違う）なので、**同じシーンを繰り返し測っても減らない。シーン数を増やすしかない。**

### 32シーンで検出できる効果量

| 検出したい効果量 | 必要なシーン数 | **32シーンでの検出力** |
| --- | --- | --- |
| +0.5 | 799 | **8%** |
| +1.0 | 200 | **20%** |
| +2.0 | 50 | 61% |
| +3.0 | 23 | 92% |

**一方、積載率50%以上の73設定における composite の実際の幅は 1.72（sd）である。**

> **つまり我々は、検出力 8〜20% の道具で、sd 1.7 の世界を測り続けてきた。**
> 「0勝24敗」の相当部分は、**効果が無かったのではなく、あっても見えなかった**可能性が高い。
> 逆に「勝った」3件は、検出力が足りる +2.6 以上の効果量だったから見えたにすぎない。

### 分散分解

| 分散源 | sd |
| --- | --- |
| シーン間（シーン難易度） | **4.94** |
| 設定間（73の安全設定） | 1.72 |
| 同一コード反復（測定ノイズ） | 0.13 |

シーン難易度の分散が設定間の分散の **2.9倍**。共通乱数（全設定を同一シーンで評価）が
必須である理由がここにある。すでに全A/Bで実施している。

## 3. 目的関数の性質

| 性質 | 内容 |
| --- | --- |
| **階段関数** | 積載率が閾値（42〜46%）未満だと fill のみ。1シーンが跨ぐと目的値が **0.67** 動く |
| **崖の近傍は少数** | 32シーン中 **6件**だけが 40〜52% にいる |
| **平坦** | 閾値の上では、方策を大きく変えても composite は 1.72（sd）の帯 |
| **ゲーム可能** | 「積まない」と composite は上がる（積載率31.7%で60.7、ただし実LBは13.6に暴落） |

**CEM が過学習した機序はこれで完全に説明できる。** 訓練で得た +3.50 は
「境界上の6件のうち約5件を跨がせた」のと同じ大きさであり、
CEM は方策ではなく**訓練セットのどのシーンが境界上かを記憶**した。

## 5. 今後の課題

### 課題1【方法論・最優先】検出力が足りていない

現在の32シーンでは +1.0 の効果量を検出力20%でしか捉えられない。
**この状態で「A/Bして負けたから却下」を続けるのは、有望な施策を捨て続けることを意味する。**

対策:
- **標準A/Bを128シーン（4プール結合）に引き上げる。** +1.0 を検出力56%、+1.5 を82%で捉えられる
- コストは4倍（1設定 ≒ 15分）だが、**却下判定の誤りのコストの方が高い**
- 却下した24件のうち、効果量 +0.5〜+1.5 の範囲だったものは**再評価に値する**

### 課題2【指標】stability が突出して低く、かつ較正されていない

5指標中で唯一 21〜25。他は 50〜87。平均変位 0.15m、荷物の70〜76%が5cm超動く。
22 → 60 なら **+7.6** で、これまでの全施策の合計を超える。

ただし**揺らし方（横0.3g×4方向×2周期）は完全な推測**であり、
本番が穏やかなら伸び代は存在しない。**較正が取れるまでは期待値そのものが不確実。**

### 課題3【探索】新しい判断基準は単独では効かない

0勝24敗。ただし課題1により、**「効果が無い」と「見えない」が区別できていない。**
現在実行中の `full14`（新特徴量7個を同時に最適化、64シーン、約14時間）が
この問いに答える設計になっている。**個別に効かないものが、同時最適化なら効くのか**を測る。

### 課題4【リスク】閾値の崖に対する保険がない

提出2枠は `OFFLINE_SEARCH` しか違わず、composite も積載率もほぼ同じ＝**分散していない**。
閾値の位置が推定値である以上、片方を積載率重視にする価値がある。**コストはゼロ。**

### 課題5【前提】5指標の重みと閾値が未確認

すべての優先順位付けが「重みは均等」「閾値は42〜46%」という未確認の仮定の上にある。
提出フィードバックの5指標内訳が**1回**見られれば、課題2の較正・重み・閾値が同時に確定する。
**工数ゼロで最大の不確実性を消せる唯一の手段。**
